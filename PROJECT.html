🔒 Security

Authentication

  • JWT in httpOnly cookie (7 days) + Bearer mirror
  • Single active session (activeSessionId)
  • tokenVersion invalidates old tokens
  • Email 2FA OTP via Gmail SMTP
  • Remember-me session duration config

Protection layers

  • bcrypt password hashing (10 rounds)
  • Login rate limit + Prisma lockout
  • Cloudflare Turnstile CAPTCHA
  • Have I Been Pwned breach check
  • Admin IP allowlist (ADMIN_ALLOWED_IPS)
  • Helmet CSP + HSTS (production)

Audit & monitoring

  • SecurityAuditLog — login, 2FA, logout
  • AccessHistory — IP, device, browser
  • CSR auto-deactivate after 90d inactivity
  • CNIC masked in API responses

Frontend guards

  • proxy.ts — JWT exp + sid validation
  • Axios 401 → clear session → login redirect
  • Role-based route separation
  • DevTools guard on login page

📋 Lead Workflow & Cron Jobs

flowchart LR Upload["Excel Upload"] --> Pending["pending"] Pending --> NP["not picked — max 7"] Pending --> NI["Not Interested — max 3"] Pending --> Important["important + schedule"] Pending --> Interested["interested"] Interested --> Close["Close Client"] Close --> Project["Active Project"] NP --> Bin["Bin — manual reassign"] NI --> Bin NP --> Shuffle["Shuffle every 2 days"] Shuffle --> Bin

Lead statuses (CSR)

  • pending, not picked, Not Interested
  • no owner available, not in service, in house
  • important, interested, Close Client

Background jobs (server.ts)

  • Auto-offline — every 5s (15s timeout)
  • Daily report — 3:30 AM → Cloudinary
  • Lead shuffle — midnight, every 2 days
  • CSR deactivation — 90d inactivity

Upload categories

  • call-data, new-client, old-client
  • interested, important, active-projects
  • Source optional (sudo name for CSR)

Chat behavior

  • Polling only when chat panel open
  • Shared chatUnreadStore dedupe
  • 4s visible / 15s hidden poll interval
  • Sound + browser notifications
